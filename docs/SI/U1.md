# Clasificación y licencias de software

## Según su propósito:
- Software de sistema (sistemas operativos)
- Software de programación (depuradores, IDE)
- Software de aplicación (videojuegos)

## Según su licencia:
- Código abierto
    - Permisivas (BSD, MIT)
    - Robustas/*Copyleft* (GNU)
- Código cerrado
    - EULA
    - Freeware
    - Shareware
    - Dominio público
